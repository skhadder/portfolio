# Sarah Khadder · Portfolio

Plain HTML, CSS and JavaScript. No build step.

## Run it
- In Cursor: open this folder, install the **Live Server** extension, then right-click `index.html` → **Open with Live Server**.
- Or just double-click `index.html` to open it in your browser.

## Where things live
- `data.js`: all your content (education, experience, projects, skills). Edit text and GitHub links here.
- `styles.css`: colors, fonts, layout. Colors are variables at the top.
- `script.js`: tabs, expanding project cards, and the mouse-reactive background.
- `assets/`: envelope, polaroid frame, clip, seal, headshot, plaster texture, grain, and the pixel video.

## Deploy
Push the folder to a GitHub repo, then import it on vercel.com or netlify.com (no settings needed).
